## 两种后端的边界

| 项目 | Comfy（原有、默认） | OpenAI-compatible 云端（新增可选） |
|---|---|---|
| 执行链 | SAM → 释放 → Comfy | VLM 提示词 → GPT Image 2 |
| 模型输入 | 上下文图 + 最终 mask | 512×512 上下文图 + 文字指令，无 mask |
| 交付 | canonical 坐标回映及局部合成 | 原始 1024×1024 生成局部图，不自动拼回 |
| 保留区域 | 原精确合成合同继续有效 | 提示词约束，用户检查；不保证区外像素不变 |
| 本地 CUDA | 原资源交接保护保留 | 不使用 SAM/Comfy，不要求本地 GPU |
