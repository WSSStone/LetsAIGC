# Data Model: Generation Backends and Assets

- **ResolvedAsset**: type, safe source, MIME, width, height, byte count, local path, SHA-256.
- **BackendCapability**: backend, intent modes, media, dimensions, alpha, stability, cost type.
- **ProviderModelEntry**: provider, snapshot, capability, terms lane, key variable, pricing id.
- **PricingEntry**: dated token rates, common-size estimates, official source, review deadline.
