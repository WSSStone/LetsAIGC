# Worktree prototype archive

This directory preserves the untracked prototype files recovered from `codex/game-ui-analysis-workflow` during the 2026-09-05 machine-migration merge.

The files are stored as `.txt` and are not part of the LetsAIGC runtime. Their schemas and function contracts predate the current 013 preview implementation. In particular, the inpaint, quality, revision and text-asset modules belong to later T019+ work and must be reconciled with the current spec and schemas before reuse.

`manifest.json` records the original paths and SHA-256 hashes.
